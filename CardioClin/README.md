# CardioClin - Sistema Completo para Clínica Cardiológica

Aplicação web para operação clínica com os módulos:

- Recepção e cadastro de pacientes com geração de senha.
- Atendimentos com status (aguardando, chamado, finalizado).
- Painel de chamadas com última chamada e histórico.
- Controle de estoque com lote, validade e alerta de vencimento.
- Financeiro com receitas, despesas e saldo consolidado.
- Relatórios rápidos operacionais.

## Como executar

1. Abra o arquivo `index.html` no navegador.
2. Use as abas para operar cada módulo.
3. Os dados ficam salvos no navegador via `localStorage`.

## Observações

- Este é um MVP funcional para uso interno e validação de fluxo.
- Para produção, recomenda-se backend com autenticação, banco de dados, permissões por perfil, logs e LGPD.
